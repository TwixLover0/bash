# Репозиторий с учебными Bash-скриптами для изучения синтаксиса,автоматизации и формирования портфолио.
1.Cкрипт автоматического обновления Manjaro(Arch Linux).
Скрипт автоматизирует полное обновление системы и пакетов из AUR,фиксируя время работы и сохраняя логи.
Вывод начала и окончания работы скрипта с помощью ``[$(date +%T)]``,``[$(date '+%Y-%m-%d %H:%M:%S')]``
Принудительное удаление старого файла блокировки ``rm -f /var/lib/pacman/db.lck`` и обновление списка зеркал ``pacman-mirrors --fasttrack 5``.
Принудительное обновление пакетов ``pacman -Syy --noconfirm`` и ``pacman -Syu --noconfirm --overwrite "*"`` (флаг --overwrite "*" используется для разрешения файловых конфликтов при переустановке пакетов.
Обновление пакетов AUR через ``yay -Sua  --noconfirm`` с сохранением вывода в текстовый файл
